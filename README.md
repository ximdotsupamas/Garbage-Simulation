# Garbage-Simulation
Lab เกมคัดแยกขยะในรูปแบบเกม 3 มิติ โดยโปรเจกต์นี้เป็นการนำ Core Mechanics เดิมของเกมต้นแบบมาดัดแปลงและ Re-design ระบบใหม่ โดยได้เพิ่มระบบ ดังนี้
- ระบบ Event โดยเมื่อคะแนนครบตามที่กำหนด จะเกิด Event การสุ่มตำแหน่งของถังขยะขึ้น

# Project Overview
- **My Role:** System Designer / Developer
- **Engine & Tools:** Unity Engine
- **Genre & Platform:** PC
- **Project Status:** Work In Progress

# What is Garbage-Simulation Game?
- **Khun Phrai (ขุนพราย)** เป็นเกมแนว **Soulslike / Survival** สำหรับผู้เล่นที่ชื่นชอบการต่อสู้ที่ท้าทายและการเอาชีวิตรอดในโลกที่เต็มไปด้วยอันตราย
ด้วยงานภาพสไตล์ **Low-poly 3D** ที่ได้รับแรงบันดาลใจจากสภาพแวดล้อมไทยโบราณ **บนแพลตฟอร์ม PC**
